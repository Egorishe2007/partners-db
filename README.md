# Учебная практика

Проект учебной практики: проектирование базы данных «Партнеры и отгрузки»,
DDL-скрипт, очистка и импорт исходных файлов, проверочные SQL-запросы.

PostgreSQL 18, скрипт очистки данных — Python 3.10.

## Структура

```
Учебная практика/
└── учебная практика_07.09.2026/
    ├── Проектирование базы данных (3NF) и ER-диаграмма/
    ├── Написание DDL-скрипта (База данных в коде)/
    ├── Подготовка данных и импорт (ETL)/
    └── Разработка проверочных SQL-запросов (Эмуляция бэкенда)/
```

Каждая папка задания самостоятельная: в ней лежит все, что нужно для
запуска, и свой README с условием, командами и результатом.

Итоговая сборка проекта — в папке «Разработка проверочных SQL-запросов
(Эмуляция бэкенда)»: там и схема, и очистка данных, и импорт, и запросы.
