# Подготовка данных и импорт (ETL)

Задание: очистить предоставленные файлы от аномалий, импортировать
подготовленные данные в СУБД и написать проверочные запросы
`SELECT COUNT(*)` по каждой таблице.

## Состав папки

| Файл | Назначение |
| --- | --- |
| `data/import_partners.csv`, `data/import_sales.txt` | исходные файлы из задания |
| `etl.py` | очистка и подготовка данных |
| `data/clean_*.csv` | подготовленные файлы для импорта |
| `data/rejected_rows.csv` | строки, которые импортировать нельзя, с причинами |
| `schema.sql` | структура таблиц (нужна перед импортом) |
| `import.sql` | импорт командой COPY |
| `import_check.sql` | проверочные запросы |

## Что нашлось в исходных файлах

| Что нашли | Где | Решение |
| --- | --- | --- |
| Лишние пробелы вокруг названия | партнеры 1 и 3 | обрезаны |
| Пустой телефон | партнер 2 | записан NULL |
| Два формата телефона: `+7 (999) 111-22-33` и `+78125554433` | партнеры 1 и 3 | приведены к виду `+7XXXXXXXXXX` |
| Пустой рейтинг | партнер 3 | записан NULL |
| Дата `15.03.2026` вместо ISO | отгрузка 102 | приведена к `2026-03-15` |
| Отгрузка на партнера `4`, которого нет в справочнике | отгрузка 104 | отклонена: внешний ключ не позволил бы ее импортировать |
| Повторяющиеся названия продукции | отгрузки 101/104 и 102/105 | вынесены в справочник `product` |

Дополнительно скрипт проверяет формат ИНН (10 или 12 цифр), формат почты,
дубликаты по ИНН и почте, дубликаты номеров отгрузок, положительное
количество и корректную сумму.

## Импорт

Импорт выполняется командой `COPY` (в psql — `\copy`), после него счетчики
идентификаторов сдвигаются на максимальный номер, иначе следующая запись
получит занятый номер.

```
psql -U postgres -d partners_db -f schema.sql
psql -U postgres -d partners_db -f import.sql
```

```
SET
COPY 3
COPY 3
COPY 4
```

## Проверка полноты импорта

```
psql -U postgres -d partners_db -f import_check.sql
```

```
 table_name | row_count
------------+-----------
 delivery   |         4
 partner    |         3
 product    |         3
(3 rows)

 orphan_delivery_count
-----------------------
                     0
(1 row)

 first_delivery | last_delivery | deliveries_amount
----------------+---------------+-------------------
 2026-03-01     | 2026-03-25    |          67000.50
(1 row)
```

Из пяти строк файла отгрузок импортированы четыре: пятая ссылается на
несуществующего партнера и отклонена на этапе очистки. Отгрузок без
партнера или без продукции в базе нет.
