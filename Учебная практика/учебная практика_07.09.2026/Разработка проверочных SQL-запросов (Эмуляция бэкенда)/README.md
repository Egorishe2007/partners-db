# Разработка проверочных SQL-запросов (Эмуляция бэкенда)

Задание: написать скрипт `queries.sql` с тремя запросами, которые будет
выполнять будущее приложение, и доказать, что база покрывает требования
заказчика.

Папка содержит итоговую сборку проекта: структуру, очистку данных, импорт
и сами запросы.

## Развертывание с нуля

```
psql -U postgres -c "CREATE DATABASE partners_db"
psql -U postgres -d partners_db -f schema.sql
python etl.py
psql -U postgres -d partners_db -f import.sql
psql -U postgres -d partners_db -f import_check.sql
psql -U postgres -d partners_db -f queries.sql
```

На Windows перед запуском psql стоит задать кодировку:

```
set PGCLIENTENCODING=UTF8
```

## 2. Добавление данных одной транзакцией

В одном блоке `BEGIN ... COMMIT` создается новый партнер, записывается его
первая тестовая отгрузка и обновляется рейтинг. Либо в базе появится все,
либо не появится ничего.

```
BEGIN
INSERT 0 1
INSERT 0 1
UPDATE 1
COMMIT
```

Повторный запуск выдаст ошибку уникальности ИНН — это и означает, что
ограничение работает.
